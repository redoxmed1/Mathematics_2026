
**4. Calculate B⁻¹A⁻¹**

Multiply the inverses in the reversed order:

B⁻¹ = 
| 1/2   0   |
| 0     1/3 |

A⁻¹ =
| 1  -1 |
| 0   1 |

Now multiply the rows of B⁻¹ by the columns of A⁻¹:

B⁻¹A⁻¹ =

| (1/2)(1) + (0)(0)     (1/2)(-1) + (0)(1) |
| (0)(1) + (1/3)(0)     (0)(-1) + (1/3)(1) |

Simplifying each entry:

B⁻¹A⁻¹ =

| 1/2   -1/2 |
| 0      1/3 |

Therefore:

B⁻¹A⁻¹ = (AB)⁻¹

**Conclusion**

Both methods give the same inverse matrix. This confirms that the inverse of a product reverses the order of the original matrices.
