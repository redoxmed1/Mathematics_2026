### Exercise 1. Recognizing Curves from Canonical Form

**Problem**

Recognize the curves:

1. x² + y² = 9
2. x²/16 + y²/9 = 1
3. y² = 8x
4. x²/9 - y²/4 = 1

For each one, identify the most important features and make a sketch. Explain which parts of the equation let you recognize the type of curve.

**Solution**

**1. Circle**

Given:

x² + y² = 9

The canonical equation of a circle is:

x² + y² = r²

Therefore:

- Center: C = (0, 0)
- Radius: r = 3
- Intercepts: (3, 0), (-3, 0), (0, 3), (0, -3)

**2. Ellipse**

Given:

x²/16 + y²/9 = 1

Comparing with the canonical form:

x²/a² + y²/b² = 1

We obtain:

- a² = 16, so a = 4
- b² = 9, so b = 3
- Center: C = (0, 0)
- Horizontal semiaxis: 4
- Vertical semiaxis: 3
- Vertices: (4, 0), (-4, 0), (0, 3), (0, -3)

The ellipse is wider along the x-axis.

**3. Parabola**

Given:

y² = 8x

The canonical form is:

y² = 4px

Therefore:

4p = 8, so p = 2

Important features:

- Vertex: V = (0, 0)
- Axis of symmetry: x-axis
- Opening direction: right
- Focus: F = (2, 0)
- Directrix: x = -2

**4. Hyperbola**

Given:

x²/9 - y²/4 = 1

Comparing with the canonical form:

x²/a² - y²/b² = 1

We obtain:

- a = 3
- b = 2
- Center: C = (0, 0)
- Vertices: (3, 0), (-3, 0)
- Opening direction: left and right

The asymptotes are:

y = (2/3)x

y = -(2/3)x

**Conclusion**

The equations identify the curves through their standard forms:

- Circle: x² + y² = r²
- Ellipse: x²/a² + y²/b² = 1
- Parabola: y² = 4px
- Hyperbola: x²/a² - y²/b² = 1
