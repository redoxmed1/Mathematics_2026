### Exercise 2. Circle by Completing the Square

**Problem**

Reduce

x² + y² - 6x + 4y - 3 = 0

to canonical form. Find the center and radius, then substitute two simple points from the circle into both forms of the equation.

**Solution**

**Step 1. Group the terms**

x² - 6x + y² + 4y = 3

**Step 2. Complete the square**

For the x terms:

x² - 6x = (x - 3)² - 9

For the y terms:

y² + 4y = (y + 2)² - 4

Substitute these expressions:

(x - 3)² - 9 + (y + 2)² - 4 = 3

**Step 3. Simplify**

(x - 3)² + (y + 2)² = 16

This is the canonical equation of a circle.

**Step 4. Find the center and radius**

The canonical equation is:

(x - a)² + (y - b)² = r²

Therefore:

- Center: C = (3, -2)
- Radius: r = √16 = 4

**Step 5. Check two points**

Choose the point:

P = (7, -2)

In the canonical equation:

(7 - 3)² + (-2 + 2)² = 16

16 + 0 = 16

The point belongs to the circle.

Now check the original equation:

7² + (-2)² - 6(7) + 4(-2) - 3 = 0

49 + 4 - 42 - 8 - 3 = 0

0 = 0

Now choose another point:

Q = (3, 2)

In the canonical equation:

(3 - 3)² + (2 + 2)² = 16

0 + 16 = 16

The point belongs to the circle.

In the original equation:

3² + 2² - 6(3) + 4(2) - 3 = 0

9 + 4 - 18 + 8 - 3 = 0

0 = 0

**Final Answer**

Canonical form:

(x - 3)² + (y + 2)² = 16

Center: C = (3, -2)

Radius: r = 4
