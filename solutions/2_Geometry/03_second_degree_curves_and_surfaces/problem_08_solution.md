### Exercise 8. Sphere

**Problem**

Reduce

x² + y² + z² - 4x + 2y - 6z - 2 = 0

to canonical form. Find the center and radius. Give two points on the sphere and check them in the equation.

**Solution**

**Step 1. Group the terms**

x² - 4x + y² + 2y + z² - 6z = 2

**Step 2. Complete the square**

For the x terms:

x² - 4x = (x - 2)² - 4

For the y terms:

y² + 2y = (y + 1)² - 1

For the z terms:

z² - 6z = (z - 3)² - 9

Substitute:

(x - 2)² - 4 + (y + 1)² - 1 + (z - 3)² - 9 = 2

**Step 3. Simplify**

(x - 2)² + (y + 1)² + (z - 3)² = 16

This is the canonical equation of a sphere.

**Step 4. Find the center and radius**

The canonical equation of a sphere is:

(x - a)² + (y - b)² + (z - c)² = r²

Therefore:

- Center: C = (2, -1, 3)
- Radius: r = √16 = 4

**Step 5. Find two points on the sphere**

Choose:

P = (6, -1, 3)

Substitute into the canonical equation:

(6 - 2)² + (-1 + 1)² + (3 - 3)² = 16

16 + 0 + 0 = 16

The point belongs to the sphere.

Choose another point:

Q = (2, 3, 3)

Substitute:

(2 - 2)² + (3 + 1)² + (3 - 3)² = 16

0 + 16 + 0 = 16

The point also belongs to the sphere.

**Final Answer**

Canonical form:

(x - 2)² + (y + 1)² + (z - 3)² = 16

- Center: C = (2, -1, 3)
- Radius: r = 4
- Two points: P = (6, -1, 3), Q = (2, 3, 3)
