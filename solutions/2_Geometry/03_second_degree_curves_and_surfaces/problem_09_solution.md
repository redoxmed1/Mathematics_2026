### Exercise 9. Ellipsoid and Its Cross-Sections

**Problem**

Consider

x²/9 + y²/4 + z²/16 = 1

Give the semiaxis lengths, describe the cross-section z = 0, and explain how the cross-sections z = c change for |c| < 4.

**Solution**

**Step 1. Identify the canonical form**

The canonical equation of an ellipsoid is:

x²/a² + y²/b² + z²/c² = 1

Comparing:

a² = 9

b² = 4

c² = 16

Therefore:

a = 3

b = 2

c = 4

**Step 2. Find the semiaxis lengths**

- Along the x-axis: 3
- Along the y-axis: 2
- Along the z-axis: 4

The ellipsoid is centered at:

O = (0, 0, 0)

**Step 3. Find the cross-section z = 0**

Substitute z = 0:

x²/9 + y²/4 + 0 = 1

Therefore:

x²/9 + y²/4 = 1

This is an ellipse in the xy-plane.

Its semiaxes are:

- Horizontal semiaxis: 3
- Vertical semiaxis: 2

**Step 4. Find the cross-sections z = c**

Substitute z = c into the original equation:

x²/9 + y²/4 + c²/16 = 1

Move the constant term:

x²/9 + y²/4 = 1 - c²/16

For |c| < 4, the right-hand side is positive.

Therefore, the cross-section is an ellipse.

As |c| increases toward 4, the right-hand side becomes smaller, so the ellipses become smaller.

**Step 5. Describe the special cases**

If c = 0:

x²/9 + y²/4 = 1

This is the largest horizontal cross-section.

If |c| = 4:

x²/9 + y²/4 = 0

The only point is:

(0, 0, 4) or (0, 0, -4)

If |c| > 4, there are no real points.

**Final Answer**

The ellipsoid has semiaxis lengths:

- x-axis: 3
- y-axis: 2
- z-axis: 4

The cross-section z = 0 is an ellipse.

For |c| < 4, the cross-sections are smaller ellipses as |c| increases.
