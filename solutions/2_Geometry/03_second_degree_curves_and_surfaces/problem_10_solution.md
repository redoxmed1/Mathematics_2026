### Exercise 10. Paraboloids

**Problem**

Compare:

1. z = x² + y²
2. z = x² - y²

For each surface, describe the cross-sections x = 0, y = 0, and z = c, then make a qualitative sketch.

**Solution**

**1. First surface:**

z = x² + y²

This surface has a minimum at the origin.

Its cross-sections are described below.

**Cross-section x = 0**

Substitute x = 0:

z = y²

This is a parabola opening upward in the yz-plane.

**Cross-section y = 0**

Substitute y = 0:

z = x²

This is a parabola opening upward in the xz-plane.

**Cross-section z = c**

Substitute z = c:

x² + y² = c

There are three cases:

- If c > 0, the cross-section is a circle with radius √c.
- If c = 0, the cross-section is the single point (0, 0, 0).
- If c < 0, there are no real points.

Therefore, the surface is a bowl opening upward.

**2. Second surface:**

z = x² - y²

This surface behaves differently in the two coordinate directions.

**Cross-section x = 0**

Substitute x = 0:

z = -y²

This is a parabola opening downward.

**Cross-section y = 0**

Substitute y = 0:

z = x²

This is a parabola opening upward.

**Cross-section z = c**

Substitute z = c:

x² - y² = c

There are three cases:

- If c > 0, the cross-section is a hyperbola.
- If c < 0, the cross-section is also a hyperbola, with the opposite orientation.
- If c = 0, we obtain x² - y² = 0.

Factor:

(x - y)(x + y) = 0

Therefore:

y = x

or

y = -x

The cross-section consists of two intersecting lines.

This surface curves upward in the x-direction and downward in the y-direction.

**Final Answer**

The first surface:

z = x² + y²

is an upward-opening circular paraboloid. Its horizontal cross-sections are circles.

The second surface:

z = x² - y²

is a saddle-shaped surface. Its vertical cross-sections are parabolas opening in opposite directions, and its horizontal cross-sections are hyperbolas except at z = 0.
