### Exercise 11. Two Similar Surfaces

**Problem**

Compare:

1. x² + y² - z² = 1
2. x² + y² - z² = -1

For several values z = c, check whether the cross-section exists and what its radius is. Based on this, describe qualitatively the difference between the surfaces and make sketches.

**Solution**

**1. First surface:**

x² + y² - z² = 1

**Step 1. Find the cross-section z = c**

Substitute z = c:

x² + y² - c² = 1

Rearrange:

x² + y² = 1 + c²

This is a circle with radius:

r = √(1 + c²)

**Step 2. Check several values**

For c = 0:

r = √(1 + 0²) = 1

For c = 1:

r = √(1 + 1) = √2

For c = 2:

r = √(1 + 4) = √5

The cross-section exists for every real value of c.

Its radius is always positive and increases as |c| increases.

**Description**

The surface has its smallest circular cross-section at z = 0.

It becomes wider in both the positive and negative z-directions.

This is a one-sheet hyperboloid.

**2. Second surface:**

x² + y² - z² = -1

**Step 1. Find the cross-section z = c**

Substitute z = c:

x² + y² - c² = -1

Rearrange:

x² + y² = c² - 1

**Step 2. Check several values**

For c = 0:

x² + y² = -1

There are no real points.

For c = 1:

x² + y² = 0

The cross-section is a single point:

(0, 0, 1)

For c = 2:

x² + y² = 3

The cross-section is a circle with radius:

r = √3

For c = -2:

x² + y² = 3

The cross-section is also a circle with radius:

r = √3

**Step 3. Describe the surface**

The cross-sections exist only when:

c² - 1 ≥ 0

Therefore:

|c| ≥ 1

There are no cross-sections for -1 < c < 1.

The surface consists of two separate parts, one above and one below the xy-plane.

This is a two-sheet hyperboloid.

**Final Answer**

For the first surface:

x² + y² - z² = 1

The cross-sections are circles for every real z. The surface is a one-sheet hyperboloid.

For the second surface:

x² + y² - z² = -1

The cross-sections exist only when |z| ≥ 1. The surface consists of two separate parts and is a two-sheet hyperboloid.
