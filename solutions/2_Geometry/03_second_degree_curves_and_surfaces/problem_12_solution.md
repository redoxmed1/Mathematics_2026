### Exercise 12. Recognizing a Surface from Cross-Sections

**Problem**

A certain surface has the following properties:

- The cross-section z = 0 is a point.
- For z > 0, the cross-sections z = const are circles with increasing radius.
- Vertical cross-sections through the Oz axis are parabolas.

Propose a simple equation for such a surface and justify your choice.

**Solution**

**Step 1. Analyze the cross-section z = 0**

The cross-section at z = 0 is a single point.

This suggests that the surface has its vertex at the origin:

O = (0, 0, 0)

**Step 2. Analyze the horizontal cross-sections**

For z > 0, the cross-sections are circles with increasing radius.

A simple equation describing circles centered at the origin in the xy-plane is:

x² + y² = r²

Since the radius increases with z, we can choose:

r² = z

Therefore:

x² + y² = z

**Step 3. Analyze the vertical cross-sections**

The proposed equation is:

z = x² + y²

Consider the vertical plane y = 0:

z = x²

This is a parabola opening upward.

Now consider the vertical plane x = 0:

z = y²

This is also a parabola opening upward.

Therefore, the equation satisfies the condition about vertical cross-sections through the Oz axis.

**Step 4. Check the horizontal cross-sections**

For z = c:

x² + y² = c

If c = 0, the cross-section is one point.

If c > 0, the cross-section is a circle with radius:

r = √c

As c increases, the radius increases.

All the given properties are satisfied.

**Final Answer**

A suitable equation is:

z = x² + y²

This is an upward-opening circular paraboloid with vertex at the origin.
