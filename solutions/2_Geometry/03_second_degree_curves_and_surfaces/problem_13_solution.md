### Exercise 13. Intersection of a Sphere and a Plane

**Problem**

Given the sphere:

x² + y² + z² = 25

and the plane:

z = 3

find the equation of the intersection curve and its radius. Then describe what happens for z = c depending on c.

**Solution**

**Step 1. Identify the sphere**

The equation is:

x² + y² + z² = 25

The center is:

O = (0, 0, 0)

The radius is:

R = 5

**Step 2. Find the intersection with the plane z = 3**

Substitute z = 3 into the sphere equation:

x² + y² + 3² = 25

x² + y² + 9 = 25

Subtract 9:

x² + y² = 16

This is a circle in the plane z = 3.

**Step 3. Find the radius**

The equation of a circle is:

x² + y² = r²

Therefore:

r² = 16

r = 4

The intersection circle has radius 4.

Its center is:

C = (0, 0, 3)

**Step 4. Study the general plane z = c**

Substitute z = c into the sphere:

x² + y² + c² = 25

Rearrange:

x² + y² = 25 - c²

There are three cases.

**Case 1: |c| < 5**

The right-hand side is positive.

The intersection is a circle with radius:

r = √(25 - c²)

**Case 2: |c| = 5**

The right-hand side is zero.

The intersection is a single point.

These points are:

(0, 0, 5) and (0, 0, -5)

**Case 3: |c| > 5**

The right-hand side is negative.

There are no real points, so the plane does not intersect the sphere.

**Final Answer**

For z = 3:

x² + y² = 16

The intersection is a circle with radius 4 and center (0, 0, 3).

For z = c:

- If |c| < 5: a circle with radius √(25 - c²).
- If |c| = 5: one point.
- If |c| > 5: no intersection.
