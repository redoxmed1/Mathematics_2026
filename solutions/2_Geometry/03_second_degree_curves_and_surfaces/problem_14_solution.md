### Exercise 14. Cone and Cylinder

**Problem**

Compare:

1. x² + y² = z²
2. x² + y² = 4

For each surface, describe the cross-sections z = c, x = 0, and y = 0, make a sketch, and explain why the radius of the cross-section depends on z in the first case but is constant in the second.

**Solution**

**1. First surface:**

x² + y² = z²

**Step 1. Cross-section z = c**

Substitute z = c:

x² + y² = c²

This is a circle with radius:

r = |c|

Therefore:

- If c = 0, the cross-section is one point.
- If c = 1, the radius is 1.
- If c = 2, the radius is 2.
- If c = -2, the radius is 2.

The radius increases as we move away from z = 0.

**Step 2. Cross-section x = 0**

Substitute x = 0:

y² = z²

Therefore:

y = z

or

y = -z

The cross-section consists of two straight lines in the yz-plane.

**Step 3. Cross-section y = 0**

Substitute y = 0:

x² = z²

Therefore:

x = z

or

x = -z

The cross-section consists of two straight lines in the xz-plane.

**Description**

The surface has a vertex at the origin and opens in both the positive and negative z-directions.

It is a double circular cone.

**2. Second surface:**

x² + y² = 4

**Step 1. Cross-section z = c**

The equation does not contain z.

Therefore, for every value of c:

x² + y² = 4

This is a circle with radius:

r = 2

The radius is always constant.

**Step 2. Cross-section x = 0**

Substitute x = 0:

y² = 4

Therefore:

y = 2

or

y = -2

The cross-section consists of two parallel lines in the yz-plane.

**Step 3. Cross-section y = 0**

Substitute y = 0:

x² = 4

Therefore:

x = 2

or

x = -2

The cross-section consists of two parallel lines in the xz-plane.

**Description**

The surface extends vertically along the z-axis.

Its circular cross-sections always have radius 2.

It is a circular cylinder.

**Final Answer**

First surface:

x² + y² = z²

- Double circular cone.
- Cross-section z = c has radius |c|.
- The radius changes with z.

Second surface:

x² + y² = 4

- Circular cylinder.
- Cross-section z = c always has radius 2.
- The radius does not change with z.
