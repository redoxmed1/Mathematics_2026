### Exercise 15. Recognition and Sketch Without a Given Name

**Problem**

Consider the two equations:

1. 4x² + 9y² - 8x + 36y + 4 = 0

2. 4x² + y² = z²

For the first equation, reduce it to canonical form, recognize the curve, give its most important features, and make a sketch.

For the second equation, do not begin by using a ready-made name for the surface. First describe the cross-sections z = c and the cross-sections by the planes x = 0 and y = 0, paying attention to the different scales along the axes. Only then identify the surface and make a sketch.

**Solution**

**Part 1. Analyze the first equation**

Given:

4x² + 9y² - 8x + 36y + 4 = 0

**Step 1. Group the terms**

4x² - 8x + 9y² + 36y = -4

Factor the coefficients:

4(x² - 2x) + 9(y² + 4y) = -4

**Step 2. Complete the square**

For the x terms:

x² - 2x = (x - 1)² - 1

For the y terms:

y² + 4y = (y + 2)² - 4

Substitute:

4[(x - 1)² - 1] + 9[(y + 2)² - 4] = -4

**Step 3. Simplify**

4(x - 1)² - 4 + 9(y + 2)² - 36 = -4

4(x - 1)² + 9(y + 2)² = 36

Divide by 36:

(x - 1)²/9 + (y + 2)²/4 = 1

This is the canonical form of an ellipse.

**Step 4. Find the center**

Comparing with the canonical equation:

(x - a)²/A² + (y - b)²/B² = 1

We obtain:

Center: C = (1, -2)

**Step 5. Find the semiaxis lengths**

A² = 9

A = 3

B² = 4

B = 2

Therefore:

- Horizontal semiaxis: 3
- Vertical semiaxis: 2

**Step 6. Find the vertices**

Horizontal vertices:

(1 + 3, -2) = (4, -2)

(1 - 3, -2) = (-2, -2)

Vertical vertices:

(1, -2 + 2) = (1, 0)

(1, -2 - 2) = (1, -4)

**Conclusion for Part 1**

The first equation describes an ellipse.

Its important features are:

- Center: C = (1, -2)
- Horizontal semiaxis: 3
- Vertical semiaxis: 2
- Horizontal vertices: (4, -2), (-2, -2)
- Vertical vertices: (1, 0), (1, -4)

The ellipse is wider horizontally than vertically.

---

**Part 2. Analyze the second equation**

Given:

4x² + y² = z²

We will study the cross-sections before identifying the surface.

**Step 1. Cross-sections z = c**

Substitute z = c:

4x² + y² = c²

For c ≠ 0, divide by c²:

x²/(c²/4) + y²/c² = 1

This is an ellipse.

Its semiaxis lengths are:

- Along the x-axis: |c|/2
- Along the y-axis: |c|

Therefore, the ellipse is twice as wide along the y-direction as along the x-direction.

If c = 0:

4x² + y² = 0

The only solution is:

x = 0, y = 0

So the cross-section is one point at the origin.

**Step 2. Cross-section x = 0**

Substitute x = 0:

y² = z²

Factor:

(y - z)(y + z) = 0

Therefore:

y = z

or

y = -z

The cross-section consists of two straight lines in the yz-plane.

**Step 3. Cross-section y = 0**

Substitute y = 0:

4x² = z²

Therefore:

z = 2x

or

z = -2x

The cross-section consists of two straight lines in the xz-plane.

**Step 4. Describe the surface**

The horizontal cross-sections are ellipses.

Their sizes increase as |z| increases.

The vertical cross-sections through the z-axis consist of two straight lines.

The surface has a vertex at the origin and extends in both the positive and negative z-directions.

Because the cross-sections are ellipses rather than circles, the surface has different scales along the x-axis and y-axis.

It is an elliptic double cone.

**Final Answer**

First equation:

Canonical form:

(x - 1)²/9 + (y + 2)²/4 = 1

It describes an ellipse with:

- Center: (1, -2)
- Horizontal semiaxis: 3
- Vertical semiaxis: 2

Second equation:

4x² + y² = z²

- Cross-sections z = c are ellipses.
- Their semiaxis lengths are |c|/2 and |c|.
- Cross-section x = 0 gives y = ±z.
- Cross-section y = 0 gives z = ±2x.
- The surface is an elliptic double cone with vertex at the origin.
